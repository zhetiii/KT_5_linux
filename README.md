# Система бронирования (BookingService)
Контрольная точка по дисциплине «Linux». Консольное Bash/TUI-приложение для управления бронированиями.

# Функционал
- Просмотр всех бронирований.
- Добавление новой брони с проверкой ввода (`read`, `if`).
- Поиск по записям с использованием утилиты `grep`.
- Статистика базы данных с использованием утилиты `wc`.

# 1. Описание проекта и тема
В качестве уникальной темы выбрана консольная Система бронирования (BookingService). Проект отличается тем, что реализует полноценный интерактивный интерфейс командной строки (TUI) с циклом меню, функциями записи данных в файлы, фильтрацией через текстовые утилиты (grep, wc) и обработкой ошибок ввода.

# 2. Структура проекта
bash-tui-project/

├── app.sh

├── README.md

└── data/

    └── bookings.txt



## 3. Команды для развертывания и запуска в Ubuntu

# Создание папки проекта и переход в нее
cd ~
mkdir bash-tui-project
cd bash-tui-project

# Создание папки для данных
mkdir data

# Назначение прав выполнения и запуск проекта
chmod +x app.sh
./app.sh

## Для защиты:
# Какая тема выбрана и чем отличается? 
Выбрана система бронирования BookingService. Отличается тем, что это интерактивное TUI-приложение с постоянным меню и базой данных в виде текстового файла. + Эта тема у меня выбрана по другой дисциплине.

# Какие пункты меню реализованы? 
1) Просмотреть все бронирования; 
2) Добавить новую бронь; 
3) Найти бронь по имени/дате (grep); 
4) Статистика и количество броней (wc -l); 
5) Выход.

# Где хранятся данные? 
В файле data/bookings.txt.

# Какие утилиты используются? 
grep для поиска по файлу и wc -l для подсчета общего числа бронирований.
